跳板机

多级 Jump Host 链式跳转，复杂网络拓扑从容应对。

下载 Bonk 返回首页
能力

复杂网络，一次配置

  • 多级跳转：A → B → C 链式配置，级数不限。
  • 可视化配置：主机条目里直接选择跳板机，不用记 ProxyJump 语法。
  • 复用凭据：每级跳板独立存 Keychain，安全且自动。
  • SFTP 同样生效：文件管理、端口转发都走跳板链路。
