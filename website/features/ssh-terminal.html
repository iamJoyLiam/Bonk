SSH 终端

多标签、水平/垂直分屏，一个窗口同时盯多台机器。

下载 Bonk 返回首页
核心能力

日常运维够用，重活也能干

  • 多标签管理：每个主机一个标签，点一下切换，标签可重命名、拖拽排序。
  • 水平 / 垂直分屏：同一会话拆成多窗格，或独立连接另一台主机，快捷键一键拆分。
  • 广播输入：一次输入同步到所有分屏面板，批量运维利器。
  • 跳板机：多级 Jump Host 链式跳转，复杂网络拓扑从容应对。
  • Zmodem：终端内直接收发文件，支持 rz / sz。
  • OSC 7 目录同步：新标签自动进入当前目录。
安全

凭据不落地

  • Keychain 凭据：密码、私钥存系统钥匙串，不在本地明文落盘。
  • Secure Enclave P256 密钥：私钥永不离开安全芯片，支持免密登录。
  • 主机密钥校验：首次连接指纹确认，防中间人。
  • SSH Config 导入：直接读取现有 ~/.ssh/config，迁移零成本。
