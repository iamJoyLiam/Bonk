Why switch

When people move from Tabby to Bonk

  • Native performance. Tabby ships an Electron runtime; Bonk is a native SwiftUI app built for Apple Silicon and Intel.
  • macOS credentials. Keys and passwords live in the Keychain, with Secure Enclave P256 key support — not a config file.
  • Quake dropdown. Global ⌘` terminal is built in; Tabby has no equivalent.
  • Workspaces. Save and restore full multi-tab layouts — Tabby has no layout save/restore.
  • Broadcast input. One command to many panes, out of the box.
Migration

Move from Tabby in 5 minutes

  1. 1

    Download Bonk and drag it into Applications.

  2. 2

    Import your SSH config: File → Import SSH Config (reads ~/.ssh/config).

  3. 3

    Add your private key in Bonk; it is stored in the macOS Keychain.

  4. 4

    Connect, then open SFTP / port forwarding from the toolbar.

  5. 5

    Save your layout as a Workspace for one-click restarts.

FAQ

Common questions

  • Is Bonk really free? Yes. Free, open source, MIT license.
  • Does Bonk support serial ports like Tabby? Yes — direct /dev/tty.* connections.
  • Can I keep Tabby for Windows/Linux? Yes. Bonk is macOS only; the two can coexist.
  • Does Bonk have plugins? No plugin system. Built-in features cover SSH, SFTP, serial, forwarding, workspaces.
