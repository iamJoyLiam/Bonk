Why switch

When people add Bonk next to iTerm2

  • SSH without ceremony. Host manager, passwords, keys, jump hosts in the UI — no ~/.ssh/config gymnastics or ssh one-liners.
  • Visual SFTP. Drag-and-drop file browser; iTerm2 has none.
  • Port forwarding panel. Local/remote/SOCKS5 with a few clicks.
  • Keychain + Secure Enclave. Keys never sit in plain config; P256 keys never leave the chip.
  • Workspaces. Save and restore whole multi-host layouts.
Migration

Move your SSH workflow to Bonk in 5 minutes

  1. 1

    Download Bonk and drag it into Applications.

  2. 2

    Import your SSH config: File → Import SSH Config (reads ~/.ssh/config).

  3. 3

    Add your private key in Bonk; it is stored in the macOS Keychain.

  4. 4

    Connect, then open SFTP / port forwarding from the toolbar.

  5. 5

    Save your layout as a Workspace for one-click restarts.

FAQ

Common questions

  • Does Bonk replace iTerm2? For remote SSH work, yes. For deep terminal-emulator features (tmux integration, scripting, profiles), iTerm2 still wins — keep both.
  • Does Bonk read my existing SSH config? Yes — File → Import SSH Config.
  • Does Bonk support tmux? It renders tmux output normally; there is no tmux-integration mode like iTerm2's.
  • Is Bonk free? Yes. Free, open source, MIT license.
