Why switch

When people move from Termius to Bonk

  • Stop paying for SSH. Core workflow — connect, browse SFTP, forward ports, jump hosts — is fully free in Bonk.
  • Prefer local credentials. Keys and passwords stay in macOS Keychain; nothing sits on a third-party cloud vault.
  • Want native feel. SwiftUI + SwiftTerm on Apple Silicon and Intel, no Electron weight.
  • SSH config already exists. Bonk imports ~/.ssh/config directly, so migration is minutes, not an afternoon.
  • Quake workflow. Global ⌘` dropdown terminal is a thing Termius simply doesn't have on desktop.

FAQ

Common questions

  • Is Bonk really free? Yes. Free, open source, MIT license. No paid tiers for core features.
  • Does Bonk have SFTP? Yes — a visual drag-and-drop SFTP browser built in.
  • Can I import my Termius hosts? Not directly (Termius has no export format), but ~/.ssh/config import covers most setups.
  • Does Bonk work on iPhone/Android? No. Bonk is macOS only. Keep Termius if mobile access is a hard requirement.
  • Is my data stored in a cloud? No. Credentials live in your macOS Keychain; sync is local and iCloud-friendly.
